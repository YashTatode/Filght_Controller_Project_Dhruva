# Flight Controller Project - Dhruva

## 🚀 Overview
This project is a rocket flight computer built using an embedded platform. It processes real-time sensor data to detect flight events and trigger the recovery system for safe descent and payload retrieval.
---

## ⚙️ Hardware Used
- ESP32
- IMU Sensor
- Bamrometric Sensor
- SD Card
- Power Supply Module

---

## 🧠 Features
- Sensor data acquisition (orientation)
- Basic stabilization logic
- Real-time control output

## 📁 Project Structure

```text

```

## ▶️ How to Run
1. Open firmware in Arduino IDE
2. Select correct board (ESP32 / Arduino)
3. Upload code to controller
4. Connect sensors and test
